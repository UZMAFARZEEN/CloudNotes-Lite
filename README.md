Project Title: CloudNotes Lite: Real-Time Cloud-Based Note Synchronization System

Description:
CloudNotes Lite is a lightweight web-based productivity tool designed to help students quickly add, manage, and delete notes in a simple and efficient way. It is browser-based and requires no installation.

Features:
- Add notes
- Delete notes
- Instant display of notes
- Persistent storage using cloud (Firebase Firestore)
- Real-time synchronization across sessions

Technologies Used:
- HTML
- CSS
- JavaScript
- Firebase Firestore (Cloud Database)

How to Run:
1. Open index.html in any web browser
2. Enter a note and click "Add Note"
3. Notes are stored in the cloud and remain even after refreshing the page

Cloud Integration:
This project uses Firebase Firestore, a cloud-based NoSQL database, to store and access notes in real time. It also supports real-time synchronization, allowing updates to be reflected instantly across sessions.
